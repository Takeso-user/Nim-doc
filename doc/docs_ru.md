# Документация

Документация состоит из нескольких документов:

- [Учебник (часть I)](tut1_ru.md) — Учебник Nim, часть I: основы.

- [Учебник (часть II)](tut2_ru.md) — Учебник Nim, часть II: продвинутые конструкции языка.

- [Учебник (часть III)](tut3_ru.md) — Учебник Nim, часть III: система макросов.

- [Руководство по языку](manual_ru.md) — Руководство по Nim; черновик, который со временем превратится в полную спецификацию.

- [Документация по библиотеке](lib_ru.md) — Описание стандартной библиотеки Nim.

- [Руководство пользователя компилятора](nimc_ru.md) — Справочник по параметрам командной строки, специальным возможностям компилятора и т.д.

- [Документация по инструментам](tools_ru.md) — Описание некоторых утилит, входящих в стандартную поставку.

- [Управление памятью](mm_ru.md) — Дополнительная документация о стратегиях управления памятью Nim и об использовании этих подходов в realtime‑сценариях.

- [Фильтры исходного кода](filters_ru.md) — Компилятор Nim поддерживает source code filters как простую, но мощную встроенную систему шаблонов.

- [Внутренняя документация](intern_ru.md) — Описывает реализацию компилятора; читать, если хотите «хакнуть» компилятор.

- [Индекс](theindex_ru.md) — Сгенерированный индекс. **Индекс + (Ctrl+F) == радость**
