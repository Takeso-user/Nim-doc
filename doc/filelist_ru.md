# Краткое описание модулей Nim

| Module | Description |
| --- | --- |
| nim | главный модуль: парсит командную строку и вызывает `main.MainCommand` |
| main | реализует верхнеуровневую диспетчеризацию команд |
| nimconf | реализует чтение конфигурационных файлов |
| syntaxes | диспетчер для разных парсеров и фильтров |
| filter_tmpl | стандартный шаблонный фильтр (`#? stdtempl`) |
| lexbase | обработка буфера лексического анализатора |
| lexer | лексический анализатор |
| parser | парсер Nim |
| renderer | рендерер кода Nim (AST обратно в текстовую форму) |
| options | содержит глобальные и локальные опции компилятора |
| ast | определения типов AST и конструкторы узлов |
| astalgo | алгоритмы для контейнеров узлов AST; преобразование AST в YAML; таблица символов |
| passes | реализует менеджер проходов по AST |
| trees | некоторые алгоритмы для узлов; модуль менее важен |
| types | модуль для обхода графов типов; содержит вспомогательные функции для работы с типами |
| sigmatch | содержит алгоритм сопоставления, используемый для вызовов `proc` |
| semexprs | содержит фазу семантической проверки выражений |
| semstmts | содержит фазу семантической проверки операторов |
| semtypes | содержит фазу семантической проверки типов |
| seminst | инстанцирование обобщённых процедур и типов |
| semfold | код для свёртки констант |
| sempаss2 | второй проход семантической проверки по AST |
| vm | содержит интерпретатор AST для вычислений во время компиляции |
| pragmas | семантическая проверка pragma |
| idents | реализует отображение идентификаторов во внутреннее представление (`PIdent`), что позволяет простым сравнением id определить эквивалентность идентификаторов Nim |
| transf | преобразования AST, необходимые перед генерацией кода |
| cgen | основной файл генератора C-кода |
| ccgutils | вспомогательные функции для генератора C-кода |
| ccgtypes | генератор C-типов |
| ccgstmts | генератор операторов |
| ccgexprs | генератор выражений |
| extccomp | вызывает C-компилятор и линкер; полезен при добавлении поддержки нового C-компилятора |
