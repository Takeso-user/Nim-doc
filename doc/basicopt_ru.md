```text
nim command [options] [projectfile] [arguments]
```

# Основные команды и опции Nim

## Команды

| Команда        | Описание                                                                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `//compile, c` | Компилирует проект с использованием генератора кода на C (по умолчанию).                                                                                                  |
| `//r`          | Компилирует проект в каталог `$nimcache/projname` и запускает полученную сборку с переданными аргументами; целевой бэкенд задаётся опцией `--backend` (по умолчанию `c`). |
| `//doc`        | Генерирует документацию для входного файла для указанного бэкенда (по умолчанию `c`).                                                                                     |

## Аргументы

`arguments` — аргументы, которые передаются запускаемой программе (если используется опция `--run`).

## Опции

| Опция                       | Описание                                                                                                                                                                                                                  |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `-p, --path:PATH`           | Добавить путь `PATH` в список путей поиска модулей.                                                                                                                                                                       |
| `-d, --define:SYMBOL(:VAL)` | Задать условный символ `SYMBOL`; опционально указать его значение `VAL` (см. «compile time define pragmas»).                                                                                                              |
| `-u, --undef:SYMBOL`        | Убрать определение условного символа `SYMBOL`.                                                                                                                                                                            |
| `-f, --forceBuild:on        | off`                                                                                                                                                                                                                      | Принудительно перестроить все модули.                                          |
| `--stackTrace:on            | off`                                                                                                                                                                                                                      | Включить/выключить вывод трассировки стека при ошибках.                        |
| `--lineTrace:on             | off`                                                                                                                                                                                                                      | Включить/выключить покомандную/построчную трассировку (для детальной отладки). |
| `--threads:on               | off`                                                                                                                                                                                                                      | Включить/выключить поддержку многопоточности.                                  |
| `-x, --checks:on            | off`                                                                                                                                                                                                                      | Включить/выключить все runtime-проверки (например range, bound, overflow).     |
| `-a, --assertions:on        | off`                                                                                                                                                                                                                      | Включить/выключить выполнение `assert`-проверок.                               |
| `--opt:none                 | speed                                                                                                                                                                                                                     | size`                                                                          | Параметр оптимизации: `none` — без оптимизаций, `speed` — оптимизация на скорость, `size` — оптимизация на размер бинарника. Для релизной сборки используйте `-d:release`. |
| `--debugger:native`         | Использовать нативный отладчик (например gdb).                                                                                                                                                                            |
| `--app:console              | gui                                                                                                                                                                                                                       | lib                                                                            | staticlib`                                                                                                                                                                 | Задать тип приложения: консольное (`console`), GUI (`gui`), динамическая библиотека (`lib`) или статическая библиотека (`staticlib`). |
| `-r, --run`                 | Запустить собранную программу с указанными аргументами.                                                                                                                                                                   |
| `--eval:cmd`                | Выполнить Nim-код, переданный в `cmd`, без создания промежуточного файла (пример: `nim --eval:"echo 1"`). По умолчанию используется nimscript (`e`); пример использования: `nim r --eval:'for a in stdin.lines: echo a'`. |
| `--fullhelp`                | Показать все доступные ключи командной строки.                                                                                                                                                                            |
| `-h, --help`                | Показать справку.                                                                                                                                                                                                         |
| `-v, --version`             | Показать подробную информацию о версии компилятора.                                                                                                                                                                       |

> Примечание: односимвольные опции, принимающие аргумент, требуют двоеточия, например: `-p:PATH`.
